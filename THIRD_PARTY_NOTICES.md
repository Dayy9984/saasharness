# Third-party notices and integration boundaries

SaaS Harness contains original workflow code and B2C-specific skill text. It is informed by, but does not vendor the complete bundles of, the following projects:

- **GitHub Spec Kit** — MIT. Used as a source for Spec → Plan → Tasks → Implement and cross-artifact analysis patterns.
- **obra/superpowers** — MIT. Used as a source for brainstorming, small tasks, RED–GREEN–REFACTOR, subagent execution, and review discipline.
- **Open Design** — Apache-2.0. Used as a source for design-contract and skill/plugin packaging patterns.
- **Impeccable** — Apache-2.0. Used as a source for independent design assessment plus deterministic/browser evidence. Optional pinned integration: `impeccable@3.5.0`.
- **UI UX Pro Max** — the repository root and package metadata state MIT, while `cli/README.md` states CC-BY-NC-4.0. It is not bundled or auto-enabled. Review the current terms before installing.
- **Cloudflare templates** — used to verify the generated React/Vite/Hono/Workers shape and dependency compatibility.

When external tools are installed, their own licenses and notices apply.
