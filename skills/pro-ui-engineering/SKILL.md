# Pro UI Engineering · Curated B2C Subset

This is an attributed, modified subset of `yzfly/pro-ui-engineering-skill`.

## Use

1. Read the approved product character, references, and anti-references.
2. Select one primary reference and at most one supporting interaction reference.
3. Read the matching file under `references/`.
4. Convert the mental model into product-specific semantic tokens; do not impersonate a brand or copy brand assets.
5. Build a running React mock with realistic B2C states.
6. Run `experience`, `design`, and `browser-evidence` critics.
7. Human approval decides the final direction.

## Curated references

- Apple-inspired interaction and physics
- Stripe-inspired transaction precision
- Linear-inspired high-speed productivity
- Notion-inspired content canvas
- Shopify-inspired Admin workbench
- Content-first AI interface
- Material-inspired consumer accessibility
- Warm B2C marketplace
- Digital physics and interruption

## Guardrails

Product intent and IA win over style. Animation may not hide latency or delay a usable state. Spring motion must express interaction or spatial meaning and include reduced-motion behavior.
